# NFSv4.2 / AFX validation — 2026-11-02

Subsequent RFC 8276 xattr and optional-operation revalidation is recorded in
[the follow-up report](nfsv42-afx-operations-2026-11-02.md). Its positive xattr
result supersedes any inference from this baseline's OPENATTR-only probe.

## Scope and implementation

The existing Rust `Mount` and Python sync/async file APIs now accept exact
`version=4.2`. Python also exposes `Version.NFS_V4_2`; an explicit ordered
`4.2,4.1` list permits fallback. The shared `src/nfs41` engine retains the
selected minor version through session bootstrap, reconnect/rebind, recovery,
lease renewal, callbacks, I/O and teardown. DS negotiation can independently
fall back to v4.1 after a definite minor-version mismatch. Error contexts retain
the applicable protocol version. Protocol rationale is in
[the RFC notes](../nfsv42-protocol-notes.md).

This is the working-tree implementation based on
`b1009a6415e9d96ae2f1dbbbf0f6fe05ef0e5b11`, built with Rust 1.95.0;
it is not a published release or evidence for the unchanged 0.9.1 registry
artifacts. COPY, SEEK, ALLOCATE/DEALLOCATE and READ_PLUS are outside this scope.

Read-only minorversion=2 COMPOUND probes succeeded on all four LIFs. File tests
ran from the existing AFX data-network executor against `/pnfs_test2`, using
AUTH_SYS UID/GID 0 and non-reserved source ports. No server configuration changed.

shared lock, prepared a unique run directory using the kernel NFSv4.2 client,

separate ordinary wheel **without** `python-test-support`, on CPython 3.11.15 /
glibc 2.34. The diagnostic wheel's manylinux_2_34 tag is for this executor only;

## Limits

Physical coverage proves normal file operations and capability negotiation on
these four AFX LIFs. It does not prove distinct-DS routing, physical callback
recall, server reboot/network-fault recovery, optional v4.2 operations, other
storage environments, a release performance gate, or registry publication.
Mixed-version DS behavior, reconnect/recovery and callback wire behavior were
verified deterministically, not by injecting faults into this physical run.
